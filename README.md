# Biologian muistiinpanot

Täältä löydät biologian muistiinpanojani, joita olen tehnyt opiskelun tueksi eri aiheista. Muistiinpanot voivat auttaa kertaamisessa, asioiden ymmärtämisessä ja kokeisiin valmistautumisessa. Sisällössä saattaa kuitenkin olla kielioppi- tai kirjoitusvirheitä, koska muistiinpanot on tehty oppimisen aikana. Pyrin päivittämään ja parantamaan niitä ajan myötä.
